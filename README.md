# egressctl
一键v4,v6出栈切换egressctl
```
wget https://raw.githubusercontent.com/wiznb/egressctl/refs/heads/main/egressctl.sh && bash egressctl.sh
```
```
============================================
 egressctl 1.2.0 - IPv4/IPv6 出栈控制
============================================
1) 关闭 IPv6 出栈   （IPv4 出网）
2) 关闭 IPv4 出栈   （IPv6 出网）
3) 优先 IPv6 出栈   （双栈保留）
4) 优先 IPv4 出栈   （双栈保留）
5) 一键恢复原始配置 （恢复备份 + 清除规则 + 清除持久化）
```
